# Harrier brand source

All Harrier artwork is generated from the pixel grids in `harrier.py`:
`MARK` is the 16 x 14 mascot, `FONT` the wordmark. Edit a grid, then:

    python3 assets/source/build.py      # needs Pillow

| Role | Color |
|---|---|
| Orange | `#FF7A1A` |
| Shade | `#C85A0E` |
| Eyes | `#1A0F08` |
| Beak | `#FFD23F` |
| Glow | `#3A1C06` |
| Background / scanline | `#120D0A` / `#18110D` |
